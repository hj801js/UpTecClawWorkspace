# Rock-Paper-Scissors

## 개요
- HTML/CSS/JS 기반 가위바위보 웹 게임
- 파일 구조: `index.html`, `script.js`, `style.css`

## 규칙
- 3파일 분리 구조를 유지한다 (HTML / JS / CSS).
- 스타일 변경은 `style.css`에서만, 로직 변경은 `script.js`에서만 수행한다.
- UI 변경 시 브라우저에서 직접 동작 확인한다.
- 외부 라이브러리 추가 시 정당성을 명시한다.
