왜 멀티 에이전트인가?

  • 단일 AI의 한계 — 컨텍스트 폭발, 역할 혼재, 검증 부재
  • 역할 분리 — 설계자가 코드를 쓰지 않고, 리뷰어가 구현하지 않는 것
  • 품질 보증 — 독립된 리뷰 단계가 있어야 실수가 걸러진다
  • 확장성 — 역할별 독립 프로세스로 병렬 처리 가능

핵심 기능

Slack Socket Mode

웹훅 없이 실시간 양방향 통신. 에이전트별 독립 Slack App으로 동시 연결.

웹 대시보드

에이전트 제어, 실시간 로그, 내부 채팅. Express + WebSocket 기반.

Handoff 시스템

에이전트 간 컨텍스트 전달. handoff.md 저장 후 세션 초기화로 깨끗한 전환.

안전장치

Circuit Breaker (5분/10회), Rate Limiter (30초/건), 워크스페이스 30GB 제한.

기술 스택

Node.js Slack Bolt Claude CLI Express WebSocket Socket Mode
  • 에이전트별 독립 프로세스 — bot/app.js ×6
  • 설정 단일 소스 — agents.json
  • 외부 DB 없음 — 파일 기반 상태 관리
  • 순수 Bash + Node.js — Python 의존성 제거
