## 1. 프로젝트 개요

### 1.1 목적

사용자가 메모를 작성·편집·삭제하고, 특정 시간에 리마인드 알림을 설정할 수 있는 웹 앱 개발.  
서버 없이 브라우저 단독 실행, GitHub Pages로 정적 배포.

### 1.2 배포 대상

- **Repository**: https://github.com/hj801js/UpTecClaw_Workspace
- **URL**: `https://hj801js.github.io/UpTecClawWorkspace/memo/`

### 1.3 제약 조건

| 항목 | 제약 |
|------|------|
| 배포 방식 | GitHub Pages (정적 호스팅만 가능) |
| 백엔드 | 없음 — 순수 프론트엔드 |
| 외부 라이브러리 | 금지 (Vanilla JS/CSS/HTML만) |
| 파일 구조 | 단일 `index.html` (워크스페이스 컨벤션) |
| 데이터 저장 | localStorage (클라이언트 전용) |

## 2. 기능 요구사항

### 2.1 메모 관리 (CRUD)

| ID | 기능 | 우선순위 | 상세 |
|----|------|----------|------|
| M-01 | 메모 작성 | P0 | 제목(선택) + 본문 입력, 색상 태그 선택 |
| M-02 | 메모 수정 | P0 | 편집 모달에서 제목·본문·색상 변경 |
| M-03 | 메모 삭제 | P0 | 확인 없이 삭제, 연결 리마인더도 함께 제거 |
| M-04 | 메모 목록 | P0 | 카드 그리드 뷰, 핀 고정 항목 상단 표시 |
| M-05 | 메모 검색 | P1 | 제목+본문 실시간 검색, 300ms 디바운스 |
| M-06 | 핀 고정 | P1 | 메모 상단 고정/해제 토글 |
| M-07 | 색상 태그 | P1 | 6가지 색상 (yellow/blue/green/pink/purple/gray) |

### 2.2 리마인더

| ID | 기능 | 우선순위 | 상세 |
|----|------|----------|------|
| R-01 | 리마인더 생성 | P0 | 날짜+시간 지정, 메모 연결(선택) 또는 독립 생성 |
| R-02 | 리마인더 수정 | P0 | 제목·날짜·시간 변경 |
| R-03 | 리마인더 삭제 | P0 | 목록에서 삭제 |
| R-04 | 리마인더 목록 | P0 | 미완료 우선, 기한 오름차순 정렬 |
| R-05 | 완료 토글 | P1 | 완료/미완료 체크박스 전환 |
| R-06 | 알림 발송 | P0 | 브라우저 Notification API 또는 앱 내 배너 (fallback) |
| R-07 | 만료 표시 | P1 | 기한 초과 항목 빨간색 강조 |

### 2.3 데이터 관리

| ID | 기능 | 우선순위 | 상세 |
|----|------|----------|------|
| D-01 | 자동 저장 | P0 | 모든 변경 즉시 localStorage 반영 |
| D-02 | JSON 내보내기 | P1 | 전체 데이터 백업 파일 다운로드 |
| D-03 | JSON 가져오기 | P1 | 백업 파일로 복원 (전체 교체 방식, 확인 다이얼로그 포함) |

### 2.4 UI/UX

| ID | 기능 | 우선순위 | 상세 |
|----|------|----------|------|
| U-01 | 다크/라이트 모드 | P1 | CSS 변수 기반 테마 전환, 설정 유지 |
| U-02 | 반응형 레이아웃 | P1 | 데스크톱: 2컬럼, 모바일: 탭 전환 |
| U-03 | 메모 편집 모달 | P0 | 오버레이 모달에서 편집 |

## 5. 사용자 시나리오

### Scenario A — 메모 작성 후 리마인더 설정
1. "새 메모" 버튼 클릭
2. 제목/본문 입력, 색상 선택
3. "리마인더 추가" → 날짜·시간 입력
4. 저장 → 메모 카드 + 리마인더 목록에 동시 반영

### Scenario B — 리마인더 알림
1. 설정한 시간 도달 시 브라우저 알림 발송
2. 알림 권한 없으면 앱 상단 배너로 표시
3. 완료 처리 시 체크박스 클릭

### Scenario C — 데이터 백업/복원
1. 내보내기 버튼 → JSON 파일 다운로드
2. 새 브라우저에서 가져오기 → 전체 복원
