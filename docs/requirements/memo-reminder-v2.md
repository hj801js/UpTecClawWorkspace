## 1. 프로젝트 개요

### 1.1 목적

사용자가 메모를 작성·편집·삭제하고, 특정 시간에 리마인드 알림을 설정할 수 있는 웹 앱.  
서버 없이 브라우저 단독 실행, GitHub Pages로 정적 배포.

### 1.2 v1 대비 변경 사항

| 항목 | v1 (`memo/`) | v2 (`memo-app/`) |
|------|-------------|-----------------|
| 폴더 | `memo/` | `memo-app/` |
| 데이터 모델 | Memo + Reminder 별도 | Reminder가 Memo에 내장 (1:1) |
| localStorage | 3개 키 분리 | 단일 키 `memoapp_data` |
| 독립 리마인더 | 지원 | 미지원 (항상 메모에 종속) |
| 색상/핀/다크 테마 | 지원 | 범위 외 (단순화) |

### 1.3 배포 대상

- **Repository**: https://github.com/hj801js/UpTecClaw_Workspace
- **배포 URL**: `https://hj801js.github.io/UpTecClaw_Workspace/memo-app/`

### 1.4 제약 조건

| 항목 | 제약 |
|------|------|
| 배포 방식 | GitHub Pages (정적 호스팅) |
| 백엔드 | 없음 — 순수 프론트엔드 |
| 외부 라이브러리 | 금지 (Vanilla JS/CSS/HTML만) |
| 파일 구조 | 단일 `index.html` |
| 데이터 저장 | localStorage 단일 키 `memoapp_data` |

## 2. 기능 요구사항

### 2.1 메모 관리 (CRUD)

| ID | 기능 | 우선순위 | 상세 |
|----|------|----------|------|
| M-01 | 메모 작성 | P0 | 제목(선택) + 본문 입력 |
| M-02 | 메모 수정 | P0 | 편집 모달/패널에서 제목·본문 변경 |
| M-03 | 메모 삭제 | P0 | 삭제 시 연결된 리마인더도 자동 제거 (내장 구조) |
| M-04 | 메모 목록 | P0 | 카드 리스트, updatedAt 내림차순 |
| M-05 | 메모 검색 | P1 | 제목+본문 실시간 검색, 300ms 디바운스 |

### 2.2 리마인더

| ID | 기능 | 우선순위 | 상세 |
|----|------|----------|------|
| R-01 | 리마인더 설정 | P0 | 날짜+시간 지정, 메모에 1:1 내장 |
| R-02 | 리마인더 해제 | P0 | 설정된 리마인더 제거 |
| R-03 | 리마인더 알림 | P0 | 브라우저 Notification API |
| R-04 | 알림 fallback | P0 | 권한 거부/미지원 시 앱 내 toast 배너 |
| R-05 | 중복 방지 | P0 | `reminderFired` 플래그로 동일 알림 재발송 차단 |
| R-06 | 만기 표시 | P1 | 기한 초과 아이콘 색상 변경 |

### 2.3 데이터 관리

| ID | 기능 | 우선순위 | 상세 |
|----|------|----------|------|
| D-01 | 자동 저장 | P0 | 모든 변경 즉시 localStorage 반영 |
| D-02 | JSON 내보내기 | P1 | 전체 데이터 백업 파일 다운로드 |
| D-03 | JSON 가져오기 | P1 | 백업 파일로 복원 (전체 교체, 확인 다이얼로그 포함) |

### 2.4 UI/UX

| ID | 기능 | 우선순위 | 상세 |
|----|------|----------|------|
| U-01 | 반응형 레이아웃 | P0 | 데스크톱 2패널, 모바일 단일 컬럼 + 모달 |
| U-02 | 메모 편집 | P0 | 데스크톱: 사이드 패널, 모바일: 전체화면 모달 |
| U-03 | 리마인더 아이콘 | P1 | 카드에 🔔 아이콘 (미설정/대기/만기 상태 구분) |

## 4. 데이터 모델 요약

```
Memo: { id, title, body, createdAt, updatedAt,
        reminder: { datetime: String|null, reminderFired: Boolean } }
```

**localStorage 키**: `memoapp_data` (단일)  
**Export 포맷**: `{ version: 1, exportedAt, memos: Memo[] }`

## 5. 사용자 시나리오

### Scenario A — 메모 작성 + 리마인더 설정
1. "새 메모" 클릭
2. 제목/본문 입력
3. 리마인더 날짜·시간 설정
4. 저장 → 카드에 🔔 표시

### Scenario B — 리마인더 알림
1. 설정한 시간 도달 → 브라우저 알림
2. 권한 없으면 앱 상단 toast 배너
3. 발송 후 `reminderFired = true` → 중복 방지

### Scenario C — 데이터 백업/복원
1. 내보내기 → JSON 다운로드
2. 새 브라우저에서 가져오기 → 전체 복원
